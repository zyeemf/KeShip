## 一、水域形状统一（默认水域 = 点构成形状）

### 1.1 背景
- 默认水域此前是"特殊渲染对象"（矩形硬编码），自定义水域是"点构成形状"（vertices 可编辑）；
- 编辑默认水域时只看到四角 A/B/C/D 一次保存后即消失（`MakeSurfaceSdf` 对 vertices 空直接兜底 mesh），无法拖拽调整形状。

### 1.2 修改
- **默认水域生成**：直接生成矩形四角 `vertices`（250×250，顺时针），与手动输入兜底/旧矩形 ksw 兜底四角同序 —— 默认水域与自定义水域行为完全一致；
- **编辑路径无条件传多边形**：`OnBtn_EditWaterArea` 不再"仅自定义水域才传 vertices"，旧矩形 ksw 水域无 vertices 时兜底为四角矩形；
- **持久化闭环**：ksw 保存/载入 vertices 后，默认水域变自定义水域，再次编辑仍可见可拖拽；
- **无回归**：`MakeSurfaceSdf` 对 vertices 空时本就走兜底 mesh，故渲染/SDF 路径不变，无性能影响。

## 二、编辑参考显示（MapWidget 新 API）

### 2.1 需求
绘制/编辑水域时，用户需要看到其他水域的位置，避免重叠或贴边。

### 2.2 实现（MapWidget）
| API | 作用 |
|-----|------|
| `setReferenceWaterAreas` | 注入参考水域列表（新增流程 = 全部水域；编辑流程 = 排除自身） |
| `fitToAll` | 相机视野按"参考水域 ∪ 当前多边形"并集适配 |
| `paintReferenceAreas` | 绘制灰虚线框 + 名称标签（只读，不参与鼠标交互） |

### 2.3 绘制顺序
参考水域绘制在模型图层**之上**、当前正在编辑的多边形**之下** —— 主次分明，参考不干扰编辑操作；绘制路径不进鼠标 hit 判定，不会误选中参考水域。

## 三、"编辑重置风浪参数"存量 bug 修复

### 3.1 现象
编辑任意水域（拖动顶点或手动改坐标）后，风/浪参数（周期/增益/风速）被清零或回默认。

### 3.2 根因
`setInitialArea` 注入参数时未携带当前 env 参数；手动输入保存路径（`onManualInput`）构造 Area 时也没有继承原 Area 的 env 参数 —— 编辑保存 = 丢失 env 参数。

### 3.3 修复
- `setInitialArea` 注入改为**先取当前值**（编辑已有水域时以当前参数为初始值）；
- 手动输入保存合并路径保留原 Area 的周期/增益/风速。

## 五、水域多边形判定修复（WaterArea::Contains）

### 5.1 现象
三角形水域：模型停在"包围盒内、多边形外"的位置不掉落 —— 误判为在水域内。

### 5.2 根因
`WaterArea::Contains` 只做 AABB 包围盒判定（`x ∈ [minX,maxX] && z ∈ [minZ,maxZ]`），完全不使用 vertices 的真实形状 —— 对非矩形水域（三角形、凹多边形）错误扩大判定范围。

### 5.3 修复（test_buoyancy_unit.cc 驱动）
```
Contains(pos)：
1. 包围盒快速拒绝（不在 AABB 内直接 false）
2. vertices < 3（纯矩形水域）→ 保持原包围盒语义
3. vertices ≥ 3 → 射线法（ray casting）水平/竖直半直线穿越计数，奇偶判定点是否在多边形内
```

### 5.4 影响面核实
| 调用方 | 结论 |
|--------|------|
| `HydroBuoyancy` 水区查询（浮力/阻尼，250 帧轮询） | 修复后一致：包围盒内先过、多边形精细判定 |
| `WavesModel` 波浪场 | 波浪在 AABB 内生成，非判定用途，不受影响 |
| 边界点（恰在多边形边上） | 射线法经严格不等式 + 边穿越规则，不重复计数 |

### 5.5 验证
- `test_buoyancy_unit` / `test_sea_state` 全部通过（单测覆盖包围盒外/内、多边形内外、矩形回归）；
- 用户实测：三角形水域"多边形外不掉落、多边形内正常"符合预期 ✅。
