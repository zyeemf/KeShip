## 四、M_A 附加质量 — ✅ 符号与量级均正确

### 4.1 DART 语义（符号判据）

- 链路：KSM `am=mij`（0-indexed 行主序）→ `InjectFluidAddedMass` → SDF `<fluid_added_mass>`（21 上三角，`m15→<xr>-405</xr>`）→ sdformat（位于 `<inertial>` 内，**与惯性同参考点 CoM**）→ DART 空间惯量 **M_total = M_RB + M_A（正号并入）**
- 运动方程 `(M_RB+M_A)·ν̇ = τ`：附加质量力 = −M_A·ν̇
- **判据**：对角元素必须为正（增大惯性）✓ 配置全正；矩阵必须**对称正定**（动能正定）✓；非对角元素符号由船体几何决定

### 4.2 配置值

m00=15, m11=360, m22=270, m33=132.5, m44=135, m55=480, m15=m51=-405（其余 0）

### 4.3 符号验证（sway-yaw 耦合 −405）✅ 正确

- 艏在 −X、艉在 +X；浮筒 x̄=1.75 **偏艉 +0.15m**（相对 CoM x=1.6）
- 耦合项 `Y_ṙ = ∫(x−x_CoM)·m_a(x)dx`：附加质量偏艉 → 积分为**负** → M_A(1,5) 为负 ✓
- 物理自洽：水动力质量偏艉 → 向右推船时艉部滞后 → 反向转向，方向正确
- 正定性：2×2 块 det = 360×480−405² = 8775 > 0 ✓；全主子式正 ✓（满足 DART 要求，否则 LINK_INERTIA_INVALID）
