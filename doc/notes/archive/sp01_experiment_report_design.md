## 第一部分：教学定位

### 对应课程

**船舶原理·静力学** — 初稳性章节（第二章）

### 前置知识

- 船体坐标系与主要尺度（船长 L、型宽 B、吃水 d）
- 重心 G、浮心 B 的定义与计算
- 阿基米德原理（浮力 = 排开水重量）
- 面积惯性矩（二次矩）的基本概念

### 本实验覆盖的知识点

| 知识点 | 符号 | 通过本实验理解 |
|--------|------|---------------|
| 浮心垂向位置 | KB | 均质圆柱 KB = d/2，吃水一半处 |
| 重心垂向位置 | KG | 均质圆柱 KG = L/2，几何中心 |
| 水线面惯性矩 | I | 圆截面 I = πr⁴/4，半径 4 次方 → 对稳性影响极大 |
| 稳心半径 | BM | BM = I/▽，水线面形状决定稳性大小 |
| 初稳性高度 | GM | GM = KB + BM − KG，判断稳性的唯一指标 |
| 稳性判据 | — | GM > 0 扶正，GM < 0 倾覆，GM ≈ 0 临界 |
| 参数化分析 | — | D/L 与密度比 s 的临界关系 |

### 与后续实验的关系

SP-02 初稳性倾斜实验将引入**非圆截面**（矩形驳船），用水线面惯性矩通用公式 $I_x = LB^3/12$ 替换本实验的 $I = \pi r^4/4$，并使用移动压载法实测 GM。本实验提供的 GM = KB + BM − KG 推导框架和物理直觉可直接复用。

### 与船舶设计的衔接

- 圆柱体水线面：$I = \pi r^4/4$ → 半径 r 对稳性是 **4 次方**影响
- 船舶水线面（近似矩形）：$I_x \approx L_{wl}B^3/12$ → 船宽 B 对稳性是 **3 次方**影响

两者都体现了"截面横向尺度对稳性的高次方敏感性"——这就是为什么集装箱船需要较大船宽来保证稳性，而窄体船（如双体船片体）必须依赖片体间距来增大整体水线面惯性矩。

## 第二部分：实验原理

### 2.1 基本假定

本实验分析的是**初稳性**（小倾角稳性），假定：
1. 倾斜角 φ 很小（φ < 10°），水线面近似保持为圆
2. 等体积倾斜——圆柱体排开水体积不变，浮心在倾斜过程中沿某一曲线移动
3. 圆柱体均质，重心 G 固定在几何中心不动

### 2.2 几何与质量参数

均质圆柱体：

| 参数 | 符号 | 关系 |
|------|------|------|
| 直径 | D | — |
| 长度 | L | — |
| 半径 | r | D/2 |
| 密度比 | s | ρ_cyl / ρ_water |
| 全体积 | ∀ | πr² · L |
| 吃水（竖直漂浮） | d | s · L |
| 排水体积 | ▽ | πr² · d = πr² · sL |

密度比 $s$ 的范围为 $(0, 1)$。$s \ge 1$ 时圆柱体沉没，不在本实验讨论范围。

### 2.3 初稳性公式推导

竖直漂浮圆柱体，水线面为半径 r 的圆：

$$I = \frac{\pi r^4}{4}$$

浮心垂向位置（距柱底）：
$$KB = \frac{d}{2} = \frac{sL}{2}$$

均质圆柱体重心垂向位置（距柱底）：
$$KG = \frac{L}{2}$$

稳心半径：
$$BM = \frac{I}{\nabla} = \frac{\pi r^4 / 4}{\pi r^2 \cdot d} = \frac{r^2}{4d} = \frac{D^2}{16sL}$$

初稳性高度：
$$GM = KB + BM - KG = \frac{sL}{2} + \frac{D^2}{16sL} - \frac{L}{2}$$

整理为：

$$\boxed{GM = \frac{L}{2} \left(\frac{D^2}{8sL^2} + s - 1\right)}$$

### 2.4 稳定性判据与临界曲线

竖直稳定条件：$GM > 0$

$$\frac{L}{2} \left(\frac{D^2}{8sL^2} + s - 1\right) > 0$$

$$\frac{D^2}{L^2} > 8s(1-s)$$

$$\boxed{\frac{D}{L} > \sqrt{8s(1-s)}}$$

**讨论**：

临界曲线 $y = \sqrt{8s(1-s)}$ 关于 $s = 0.5$ 对称，最大值在 $s = 0.5$ 处达到 $y_{max} = \sqrt{2} \approx 1.414$。

| s 区间 | 物理含义 | GM 主导项 |
|--------|---------|----------|
| s → 0（极轻，如泡沫） | 吃水极浅，KG ≈ L/2, KB ≈ 0, 但 BM = D²/(16sL) → ∞ | BM 主导，GM 很大 |
| s ≈ 0.5（中密度，如松木） | 吃水适中，最易失稳 | KB-KG = -L/4，完全靠 BM 弥补 |
| s → 1（极重，如橡木） | 吃水接近全长，KB ≈ KG ≈ L/2 | KB-KG ≈ 0，仅需少量 BM 即可稳定 |

这是一个反直觉但物理上正确的结论：**极轻和极重都容易竖直稳定，中等密度反而最难稳定**。

### 2.5 倾倒后的稳态

当 $GM < 0$ 时，竖直状态不稳定。圆柱受扰动后横倾，最终稳定在水平漂浮状态。此时水线面变为近似矩形（圆柱侧面投影），水线面惯性矩远大于圆截面，因此水平姿态是稳定的。

### 3.1 新实验流程

```
学生选择 D, L, ρ → 点击"生成圆柱体" → Gazebo spawn
→ 实时显示横倾角 φ(t)、吃水 d、GM 理论值
→ 点击"施加扰动" → 系统施加水平脉冲
→ 观察 φ(t) 变化：扶正回 0° / 倾倒至大角度
→ 记录判定结果（稳定/不稳定/临界）
→ 换参数重复
→ 查看稳定域图
```

### 3.3 实现要点

**圆柱体生成**：
- 复用 `SpawnCylinderInGazebo`，接收对话框传来的 D/L/ρ
- 密度 ρ 通过调整圆柱体模型质量实现（SDF `<inertial><mass>`）
- 每次生成前自动删除已有 SP-01 圆柱体

**横倾角测量**：
- 订阅 `/world/keship_world/pose/info`
- 从圆柱体 orientation 四元数提取 roll 角（绕 X 轴旋转）：φ = atan2(2(qw·qx + qy·qz), 1−2(qx²+qy²))

**扰动机制**：
- 预设三档：轻推（目标横倾 ~3°）、中推（~5°）、重推（~10°）
- 向圆柱体顶部施加水平短脉冲力（~0.2s），通过 `ExternalWorldWrenchCmd` 或推力 topic
- 优点：每次扰动强度一致，便于对比不同参数组的响应

**稳定/不稳定判定**：
- 施加扰动后，在 5s 内连续监测 φ(t)：
  - φ → 0°（衰减回零）→ 竖直稳定
  - φ → 大角度（持续增长并稳定在水平附近）→ 不稳定
- GM ≈ 0 的点：扶正极慢或行为不确定 → 标注为"临界"

**数据记录**：
- 数据表列：D, L, ρ, s, D/L, GM(理论), D/L_临界, 稳定?

**稳定域图**：
- 横轴 s，纵轴 D/L
- 理论临界曲线 $y = \sqrt{8s(1-s)}$ 连续绘制
- 实验数据点标注：稳定 ○（绿色）、不稳定 ×（红色）
