# 设备结构模型（内置）

本目录存放**非传感器**器件的结构模型，只用于 3D 场景显示：不产生 topic、不产生数据、不参与任何物理量。

## 文件（按类型稳定命名，一个类型一个文件）

| 文件 | 用于 | 挂载方式 |
|---|---|---|
| `thruster.glb` | 推进器 | 位置/朝向**取自推进器配置**（`===THRUST===` 段），不单独录入 |
| `battery.glb` | 电池 | 由「设备装饰」对话框录入位置/朝向（`===DEVICES===` 段） |
| `motor.glb` | 电机 | 同上 |
| `controller.glb` | 控制器（控制盒） | 同上 |

缺文件时该器件**不显示**，只在终端告警一次；不影响传感器，也不影响任何物理量。

## 建模约定

- 单位：1 BU = 1 m（不要为「看得见」放大）
- 导出：glTF/GLB，Y-UP（导出器负责转轴，不在建模软件里转）；平台加载时统一转到 Z-UP
- 原点：**安装面中心**（器件底面中心），模型自安装面向上生长
- 推进器额外要求：**+X 为推力方向**（推力沿节点局部 +X），+Z 向上
- 朝向若与上述不符，装配到场景里会躺倒或反向，需要重导或在装饰对话框里补角度

## 缓存

首次加载会在本目录下生成 `normalized/`（标准化 OBJ + MTL）。该目录**不入库**、可安全删除，删后自动重建。
